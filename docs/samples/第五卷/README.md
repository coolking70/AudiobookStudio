# 第五卷 样本

按卷归档的说话人归因样本。本卷目前收录 `muli_5`（《我和班上最讨厌的女生结婚了》第五卷）
成品音频的**人工书签纠错集**。

> 命名沿用书签 `trackId` 里的中文卷名（`第五卷/muli_5_part_001`）。muli4 的 seg 评测样本
> 仍是 `docs/samples/` 下的扁平命名（被 `tools/parse_sample.py` 等按路径硬编码引用），未移动。

## 文件

| 文件 | 内容 |
|---|---|
| `原文.txt` | 第五卷全卷原文（轻小说库版，`「」`对白、无显式说话人） |
| `原文_part001.txt` | 从全卷切出的 part_001 对应段（36,474 字，止于 segment 750 真唯台词） |
| `muli5_part001_bookmark_regression.json` | part_001 全片（750 段）听感书签 + 逐处归因纠错 |
| `build_muli5_bookmark_regression.py`（在 `tools/`） | 由 LRC + 优化快照 + 书签 + 原文确定性重建本 JSON |

重建：`python tools/build_muli5_bookmark_regression.py`

> `原文_part001.txt` 是评测/复核的**正文 ground truth**：书签只标到 45 处，而原文逐段比对
> 能发现书签漏掉的错判（见下「补充审计」）。切割边界 = 全卷原文中 segment 750 台词
> 「我当然想……我的喜欢，就是这样的东西……」的句末。

## 与 muli4 书签样本的口径差异

muli4 有「原始快照 + 人工复核快照」两份，故每段带 `raw`/`reviewed`。本卷**只有一份
生成时实际使用的优化快照**（用户对照成品音频下书签），因此：

- `raw_speaker == reviewed_speaker` = 生成时实际用的说话人；
- `expected_speaker` = 人工判定的正确说话人；二者不同即一处归因错误。

## 数据规模

- `manual_bookmarks`：45 处人工书签（含时间、label、命中 LRC 行及 ±2 行上下文）；
- `corrected_segments`：43 处确认归因错误（`via=bookmark` 42 处 + `via=audit` 1 处），带 `reason`
  + 完整 `raw` 字段；
- `flagged_but_correct`：3 处书签标到但核对后归属正确（行 315 / 379 / 738，疑边界误听）；
- `audit_suspected`：1 处原文复核存疑、待听感确认（行 280）。

## 补充审计（书签之外，逐段对照原文）

把全部 750 段说话人与 `原文_part001.txt` 逐段比对（而非只看 45 处书签）后，新增发现：

- **行 228**（`via=audit`，已并入 `corrected_segments`）：「是这样没错……」被判 `小柳香穗`，
  原文中香穗[227]「这种事交往前就知道了吧」后是玲奈子认输接话，下句旁白「不过她没有安慰我」
  证实[228]=玲奈子。属**话轮相位错一格**（227/228 连着挂给香穗）。
- **行 280**（`audit_suspected`，存疑）：「是要用球技大赛来一决胜负的意思吗？」被判 `小柳香穗`，
  但香穗上句「果然啊～」已表示听懂，这句困惑提问更像玲奈子。原文无显式标记，待听感确认。

> 其余未被书签覆盖的区域（开头纱月表白、屋顶三人戏、紫阳花电话、纱月登门/道歉、豪华轿车）
> 逐段核对**归属正确**；流水线自带的 `_needs_review`/低置信标记在本片约命中 300 段，绝大多数为
> 误报（第一人称旁白用旁白嗓、或双人对话正常轮换），印证 docs 所述其 precision 偏低。

## 错误根因（42 处归因错误的归类）

1. **称呼被当成说话人**（最主要）：台词里出现「X同学／姐姐」时，把*被称呼者*判成说话人。
   称「玲奈子同学」的台词被挂回甘织玲奈子本人（310/318/325）；称/提「纱月同学」「真唯」的
   被挂给纱月/真唯（556/604/661/590/651）。
2. **「姐姐」关键词触发的"甘织遥奈"误修正**：evidence 反复出现「主叙述者台词称呼『姐姐』，
   由甘织玲奈子修正为甘织遥奈」。在遥奈**尚未登场**的紫阳花通话场景（428/431/455）与玲奈子
   自述（530）被强行改判为遥奈。
3. **叙述/独白未归旁白**：引号外叙述（324，attribution 已是 narrator+conf1）、章节/栏目/卡牌名
   （330/506）、独白举例（334/336/398）被分给具体角色。
4. **场景人物表含不在场角色**：妈妈早餐场景（671/672）、紫阳花通话（428/429）混入真唯/纱月/
   遥奈，导致整段轮换相位错位（361↔362、511↔514、692/743 互换）。
5. **新角色照泽耀子在自我介绍处未注册**：致其整段台词被分流给高田卑弥呼或玲奈子（310/314/
   318/325）。

> 注：45 处书签里 34 处系统自身已标 `_needs_review=True` 或置信 ≤0.69 —— 审计阶段已分流，
> 但复核/合并未落地纠正；另有数处**高置信仍错**（314=0.9、324=conf1、389=0.92、651=0.85），
> 复核兜不住，需从根因 1/2/3 的规则层面修。
