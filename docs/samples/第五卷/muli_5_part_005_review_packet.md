## 判定优先级（从强到弱）
1. 紧邻旁白点名：下一句旁白「X说道/X的声音/X低头/X撂下…」→该台词是 X（注意「…说道：」是引出下一句、不是上句）
2. 称呼≠说话人：台词在喊「X同学/小X/X前辈/宝贝」→说话人**不是** X 本人；「我是X」自我介绍→就是 X
3. 口癖：含「喵」→小柳香穗
4. 只在【候选/在场】里选；不在场的角色基本排除
5. 双人对话严格轮换 A→B→A→B
