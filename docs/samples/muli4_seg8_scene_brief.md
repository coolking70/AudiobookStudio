场景摘要：
玲奈子以第一人称视角叙述，和小香穗穿着 Cosplay 服坐在活动会场饮食区，观看之前的直播存档和活动后续。随后她们在会场遇到以 moon 身份活动的琴纱月、紫阳花、王冢真唯等人，围绕 Cosplay、活动排名、真唯登场、紫阳花是否同行等话题展开多人对话。

身份事实：
- 叙述者/“我”/小玲奈/玲奈亲 = 甘织玲奈子。
- 小香穗/香穗 = 小柳香穗。
- moon/moon小姐/帕曼小姐/纱月/小纱月 = 琴纱月。
- 紫阳花同学/小紫 = 濑名紫阳花。
- 真唯 = 王冢真唯。

场景约束：
- 台词中的“moon”“帕曼小姐”应按身份归并为琴纱月，但仍需结合局部前后文判断是否真是她说出。
- 第一人称“我”的外显台词通常归甘织玲奈子；内心想象/引用他人消息时不要机械归给玲奈子。
- “小香穗”说话常带轻松吐槽、网络语和“喵”等语气；但语气只能辅助，不能压过明确动作主语。
- 多人同场时不要只按轮换改判，优先使用台词前后的动作主语、后文明示、被点名回应、身份别名归并。
